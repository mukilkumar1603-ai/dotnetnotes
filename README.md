# VB.NET Complete Notes (static website)

Plain HTML, CSS and JavaScript. No build step, no server needed.

## Run locally
Double-click `index.html`.

## Publish on GitHub Pages
1. Create a new repository on GitHub (e.g. `vbnet-notes`).
2. Upload all files from this folder (keep the `css` and `js` folders).
3. Repository > Settings > Pages > Source: "Deploy from a branch" > Branch: `main`, folder `/ (root)` > Save.
4. Your site appears at `https://<your-username>.github.io/vbnet-notes/` in about a minute.

## Edit content
All notes live in `js/data.js`. Colours and layout are in `css/style.css`.
